# zoningbase.com

Astro 5 (SSR, `@astrojs/cloudflare` adapter) + D1, programmatic US zoning code database. GA4 property 531851676, measurement ID `G-GQX27HNP19` (installed in `src/layouts/Base.astro`).

**Deploy method (verified 2026-07-10): NOT git-push auto-deploy.** The `zoningbase` Cloudflare Pages project has no Git provider connected (`wrangler pages project list` shows Git Provider "No"; last automatic build was 2026-04-08, commit `c6ad725`, three commits before the contact/about/privacy pages were even added). Every commit since then only went live because someone ran the CLI deploy. To ship: `git push` (for history/CI) THEN `npm run deploy` (runs `astro build && wrangler pages deploy dist --project-name zoningbase`) from the repo dir with an authenticated `wrangler`. Do not assume push alone deploys this repo.
